# Jobs

Job map only. The linked skills own the steps; [contracko](../SKILL.md#find-the-right-tool) owns tool choice.

## Add your first contract

**They say:** I just signed up; add this contract.

Follow [first-contract intake](../../contracko-import/SKILL.md#managed-import).

**Done when:** the contract reads back in the intended workspace and the user knows extraction is pending review.

## Bring contracts in

**They say:** import, onboard, migrate; files on disk, Drive, SharePoint or Box.

Follow the [import or sync rule](../../contracko-import/SKILL.md#choose-import-or-sync). For cloud-drive files, download or fetch the file with the available connector, then import it.

**Done when:** the requested files are contracts in the intended workspace.

## What is coming up

**They say:** notice dates, end dates, renewals, annual review, reminders, notifications.

Follow [calendar](../../contracko-review/SKILL.md#calendar-notice-end-annual-review) and [notifications](../../contracko-review/SKILL.md#events-and-notifications).

**Done when:** the user has the urgent bucket, its dates, and any requested notification confirmed as created.

## Compare these

**They say:** proposals, vendor A/B, redline versus draft.

Follow [comparison](../../contracko-review/SKILL.md#compare-proposals-and-versions).

**Done when:** the user can choose with supporting quotes.

## Audit for risk

**They say:** liability, caps, indemnity, exposure.

Follow [audit](../../contracko-review/SKILL.md#audit-risk-and-liability).

**Done when:** findings have evidence, severity and extraction-review status.

## File and type contracts

**They say:** organise, folders, types, custom fields.

Follow [workspace organisation](../SKILL.md#organise-the-workspace).

**Done when:** requested configuration and filing changes read back correctly.

## Priorities and gaps

**They say:** portfolio, this quarter, what is missing.

Follow [reporting](../../contracko-review/SKILL.md#report-priorities-gaps-vendors).

**Done when:** results name priorities, gaps and the completed result-set count.

## Start a new agreement

Follow [contracko-create](../../contracko-create/SKILL.md) for the questionnaire, app drafting/signature handoff and filing the executed copy.
